## Architecture / Decisions
- Layout split confirmed: `src/backend/hotel_assistance/` (Python package) vs. `src/frontend/`
  (plain HTML/CSS/JS, no build step), matching AGENTS.md.
- OpenAI is the sole LLM provider; the Ollama scaffold was removed rather than kept as dead code.
- Retrieval is hybrid by default (embeddings + deterministic keyword aliases), selectable via
  `HOTEL_ASSISTANCE_RETRIEVAL_MODE`.
- Reasoning-family models (`gpt-5*`, `o1/o3/o4`) are detected by prefix and never sent an explicit
  `temperature`, since the API rejects it for those models.
- A `false` boolean value is treated as "explicitly absent" and never triggers a conflict against
  another filter — only a genuinely active request can conflict.
- Backend/API failures on offer-counting degrade to `available_offers_count=None` rather than
  fabricating a count (AGENTS.md invariant).
